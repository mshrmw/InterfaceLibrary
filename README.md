## Написать программу, реализующую систему для управления библиотекой книг. Система должна поддерживать добавление, удаление и поиск книг по автору или названию. Необходимо реализовать двумя способами: с помощью классов и с помощью интерфейсов. 
### Решение с помощью интерфейсов:
Создать интерфейс IBook с свойствами Title и Author.
Создать класс Book реализующий интерфейс IBook и метод ToString().
Создать класс Library с коллекцией интерфейсов IBook и методами AddBook(IBook book), RemoveBook(IBook book), FindBookByTitle(string title) и FindBooksByAuthor(string author).
